Medlemmar är: Alexander Hellsten, Calle Nilsson
Hur spelet körs: Startas via visual studios, måste ha .net10 och visual studios 2026
Fil som startar programmet: MauiProgram.cs
Ansvars indelning: Calle har ansvar för frontend och Alex har ansvar för backend
hur har ni arbetat med projektet: vi har arbetat hemifrån med möte via teams
